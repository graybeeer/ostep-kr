# 개요

[English 원문](README.md)

이 장에는 두 가지 시뮬레이터가 있습니다. 첫 번째인 `fork.py`는 프로세스가 생성되고 종료될 때 프로세스 트리가 어떻게 바뀌는지 보여 주는 간단한 도구입니다. [한국어 사용 안내](README-fork-kr.md)를 읽어 보세요.

두 번째인 `generator.py`는 `fork()`, `wait()`, `exit()`를 사용하는 실제 C 프로그램을 생성합니다. 실행 중인 프로그램에서 `fork`가 어떻게 동작하는지 확인할 수 있습니다. [한국어 사용 안내](README-generator-kr.md)를 읽어 보세요.
