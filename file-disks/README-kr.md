# 개요

[영어 원문](README.md)

`disk.py`는 디스크 동작을 살펴보는 시뮬레이터입니다. 실행 옵션이 많으며, 다른 숙제와 달리 그래픽 애니메이션도 제공합니다. 이 문서는 기본 사용법을 설명합니다.

`disk-precise.py`는 부동소수점 계산 대신 Python의 `Decimal`을 사용하는 실험 버전입니다. 일부 경계 사례에서 더 정확할 수 있지만, 원문에서도 충분히 테스트하지 않았다고 안내합니다.

> 아래 명령어와 출력 예시는 원문을 보존했습니다. 이 저장소의 터미널 설명은 한국어이며 GUI 표기는 영어입니다. `prompt>`는 입력하지 마세요. `disk.py` 또는 `./disk.py` 대신 `python3 disk.py`로 실행할 수 있습니다. 그래픽 모드는 화면과 Tk를 사용할 수 있는 환경이 필요합니다.

## 단일 요청과 회전 지연

시뮬레이터에는 디스크 요청을 지정하거나 무작위로 생성해야 합니다. 먼저 섹터 10에 대한 단일 요청을 지정합니다.

```sh
prompt> disk.py -a 10
```

다음과 같이 완료 시간을 계산해 보라는 출력이 나옵니다.

```sh
...
REQUESTS [br '10']

For the requests above, compute the seek, rotate, and transfer times.
Use -c or the graphical mode (-G) to see the answers.
```

시간을 구하려면 섹터 배치와 헤드 위치를 알아야 합니다. `-G`로 그래픽 화면을 열어 봅시다.

```sh
prompt> ./disk.py -a 10 -G
```

헤드는 가장 바깥쪽 트랙의 섹터 6 중간에 있습니다. 같은 트랙의 섹터 10을 읽으려면 디스크가 대략 3분의 1바퀴 돌아야 합니다. 디스크는 반시계 방향으로 회전합니다. 창에 포커스를 둔 상태에서 `s`를 누르면 시작하고, `q`를 누르면 종료합니다.

완료 후 회전 대기 시간은 105, 전송 시간은 30, 탐색 시간은 0입니다. 기본 회전 속도는 시간 단위당 1도이므로 한 바퀴에 360시간 단위가 걸립니다.

전송은 섹터 9와 10 사이의 경계에서 시작해 섹터 10과 11 사이의 경계에서 끝납니다. 한 트랙에 섹터가 12개이므로 각 섹터는 30도이고, 전송에도 30시간 단위가 걸립니다. 헤드가 이미 같은 트랙에 있으므로 탐색은 필요 없습니다.

처음 위치인 섹터 6의 중간에서 섹터 9의 중간까지 90도, 거기서 섹터 10의 시작 경계까지 15도를 기다립니다. 따라서 회전 지연은 `90 + 15 = 105`입니다.

## 연속된 두 요청

```sh
prompt> ./disk.py -a 10,11 -G
```

실행 전에 총시간을 예상해 보세요. 섹터 10을 읽은 직후에는 섹터 11이 바로 이어집니다. 따라서 추가 탐색이나 회전 대기 없이 전송 시간 30만 더 필요합니다. 전체 탐색·회전 시간은 이전과 같고, 전송 시간은 두 배입니다. 창 위쪽과 터미널에 합계가 표시됩니다.

```sh
...
Sector:  10  Seek:  0  Rotate:105  Transfer: 30  Total: 135
Sector:  11  Seek:  0  Rotate:  0  Transfer: 30  Total:  30
TOTALS       Seek:  0  Rotate:105  Transfer: 60  Total: 165
```

## 다른 트랙으로 이동하기

이번에는 섹터 10 다음에 섹터 18을 요청합니다.

```sh
prompt> disk.py -a 10,18 -G
```

트랙 사이의 거리는 40거리 단위이고, 기본 탐색 속도는 시간 단위당 1거리 단위입니다. 따라서 바깥쪽 트랙에서 가운데 트랙으로 이동하는 데 40시간 단위가 걸립니다.

기본 정책은 FIFO입니다. `-a`에 적은 순서대로 요청을 처리합니다. 섹터 10은 앞과 같이 135시간 단위가 걸립니다. 섹터 18은 먼저 가운데 트랙으로 이동하고, 해당 섹터가 헤드 아래 올 때까지 기다린 뒤, 30시간 단위 동안 전송합니다.

탐색 시간이 0이라고 생각하면 회전 대기는 210입니다. 바깥쪽 섹터 10은 가운데 트랙의 섹터 22와 정렬되어 있습니다. 그 끝에서 섹터 18의 시작까지는 23, 12, 13, 14, 15, 16, 17의 일곱 섹터를 지나므로 `7 × 30 = 210`입니다.

하지만 **헤드가 이동하는 동안에도 디스크는 회전합니다.** 탐색 40 동안 이미 회전했으므로 남은 회전 대기는 `210 - 40 = 170`입니다. 그래픽 없이 정답을 확인하려면 `-c`를 사용합니다.

```sh
prompt> ./disk.py -a 10,18 -c
...
Sector:  10  Seek:  0  Rotate:105  Transfer: 30  Total: 135
Sector:  18  Seek: 40  Rotate:170  Transfer: 30  Total: 240
TOTALS       Seek: 40  Rotate:275  Transfer: 60  Total: 375
```

이제 기본 동작을 알았으니 교재의 문제를 풀며 다른 옵션과 디스크 스케줄링 정책을 탐색해 보세요.
